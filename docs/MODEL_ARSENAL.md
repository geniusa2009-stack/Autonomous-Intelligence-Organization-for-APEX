Reading guide:

* **Integration** = code maturity. `IMPLEMENTED` is reserved for engines whose code runs in this repository's test suite. `CONFIGURED_BUT_UNTESTED` = real client code exists but has never been run against the real model/provider (only mocked transports). `NOT_YET_SUPPORTED` = registered, invoking raises `DesignNotSupported` with the reason.
* **Licence** = verified production state. Every external model is `UNKNOWN` (or more restrictive) until a human records a verification; `reported` is prior knowledge and grants nothing.
* **Routes** = where it could run at $0. Remote routes additionally need a live $0 price check or a human free-tier attestation before the ZeroCostFirewall allows them.
